# Simulation d'une grille sur USDG/USDC, sans argent

Ce dépôt fait tourner une simulation. Il ne passe aucun ordre et ne contient aucune clé.
Le script lit le carnet et les transactions publics de Kraken toutes les 30 secondes et fait comme si ses
ordres étaient posés. Les règles et le jugement sont écrits dans l'en-tête de `simu_grille.py`.

Résultat courant : `simu_grille.md`. État : `donnees/simu_grille/`.
